# BioCoach
Микросервис рекомендаций для мобильного приложения, работающий под высокой нагрузкой.

**Смысл:** пользователю нужен мгновенный ответ на вопрос «что мне принять под мой текущий уровень стресса?». SQL-запросы к БД при каждом открытии приложения это медленно и дорого. Сервис проверяет кэш,если рекомендация есть отдаст за миллисекунды, если нет, делает grpc вызов и кэширует результат.

**Возможности**
* **gRPC + Protobuf** — бинарный протокол HTTP/2 для межсервисного обмена, быстрее REST/JSON.
* **Redis Cache (Cache-Aside)** — хранение рекомендаций с TTL для разгрузки основной базы данных.
* **Защита от Cache Stampede** — распределенные блокировки, при лавине одинаковых запросов в БД идет только один поток, остальные ждут кэш.
* **Сквозное логирование** — перехватывает все вызовы, пишет время выполнения и ошибки без дублирования кода.
* **REST API Gateway** — единая точка входа, конвертация Protobuf ответов в JSON, валидация параметров и маппинг grpc ошибок в HTTP-статусы.

**Технологии**
Java, Spring Boot, grpc, Protobuf, Redis, Gradle, Docker, JUnit
